--- layout: example.html title: WebGL Reprojection shortdesc: GPU reprojection of WebGL raster tiles and vector features. docs: >

Use the CRS dropdown to change the projection of the view. Both raster and vector layers are reprojected at render time.

WebGL vector layers keep features in a fixed feature CRS and warp them to the view when needed. If a VectorSource omits projection, the renderer assigns one from the format's dataProjection (e.g. EPSG:4326 for GeoJSON) or, if that is unavailable, from the view on first render. Setting projection explicitly is optional but makes the feature CRS obvious. When the source projection matches the view, the non-reprojecting fast path is used.
